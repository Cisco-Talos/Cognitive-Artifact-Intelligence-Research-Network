# PROMPTSTEAL — See LAMEHUG

PROMPTSTEAL is the PyInstaller-packed Windows PE variant of the **LAMEHUG** family. It is documented in the unified family report alongside the bare Python script form.

**Full report:** [LAMEHUG.md](LAMEHUG.md)

The two variants share lineage, infrastructure, and the core LLM-directed reconnaissance workflow, but differ in archetype: LAMEHUG (bare script) is **A7**, while PROMPTSTEAL (packed PE) is **A6**, because only the packed form harvests credentials from the victim host. The Archetype Divergence section of the unified report explains this distinction in full.
